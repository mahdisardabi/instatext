# InstaText

A lightweight, free and open-source Persian/English Instagram content helper.

## Current features

- Persian RTL interface
- Caption templates with multiple tones
- Basic hashtag suggestions
- Copy-to-clipboard
- No backend
- No installation required

## Run locally

Open `index.html` in a browser.

## Roadmap
